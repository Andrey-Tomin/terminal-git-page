# План интеграции умных подсказок для Linux-команд

## Цель
Добавить в терминал функцию "Smart Hints" — всплывающее окно или боковую панель, которая объясняет смысл вводимой команды и показывает примеры её использования в реальном времени.

## Лучший выбор: Интеграция базы TLDR (Too Long; Didn't Read)

### Почему это подходит нам:
- **Структура**: Данные хранятся в формате Markdown/JSON, что идеально для React.
- **Популярность**: Охватывает 99% команд, которые реально используют люди.
- **Примеры**: Вместо сухой теории показывает готовые строки кода (например: `tar -xvf file.tar.gz`).

---

## Архитектура реализации

### 1. Подготовка данных (Backend/Rust или Frontend)
- **Вариант А (Оффлайн)**: Скачать архив TLDR (около 10-15 МБ) и положить в `src/assets/tldr`.
- **Вариант Б (API)**: Запрашивать данные с публичного API при вводе команды (требует интернет).
- **Рекомендация**: Оффлайн-вариант лучше для профессионального терминала.

### 2. Логика перехвата ввода
- В компоненте `XTerm.tsx` мы уже отслеживаем ввод символов.
- При нажатии `Space` (пробел) берем первое слово из буфера (это и есть команда).
- Ищем это слово в нашей базе.

### 3. Интерфейс (UI)
- **Tooltip**: Маленькое окошко прямо над курсором терминала.
- **Sidebar**: Информация появляется в правой панели (там, где сейчас история).
- **Command Palette**: Выпадающий список при нажатии `Ctrl+Space`.

---

## Что нужно добавить в проект (библиотеки):
1. **Fuse.js**: Для мгновенного нечеткого поиска по командам (если пользователь ошибся в букве).
2. **React-Markdown**: Для красивого отображения форматированного текста из базы TLDR.

## Преимущества для пользователя:
- Не нужно лезть в Google, если забыл флаг команды.
- Снижение риска фатальных ошибок (например, перепутать флаги в `rm`).
- Ускорение обучения для новичков.
